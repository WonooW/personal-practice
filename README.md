## 휴대폰 설치 방법

1. 위의 **안드로이드 앱 받기**를 누릅니다.
2. 다운로드한 APK 파일을 엽니다.
3. Android에서 설치 권한을 요청하면, 사용한 브라우저나 파일 앱의 **이 출처의 앱 설치 허용**을 켭니다.
4. **설치**를 누르고 **Donghwa Commissioning** 앱을 실행합니다.

Android 7.0 이상 ARM64 기기용 테스트 설치 파일입니다. 아이폰에서는 설치할 수 없습니다.

Qingdao 기본 토폴로지, 8개 화면, 수동·계기 매핑 입력, 계산·진단, SQLite 프로젝트 및 운전 기록 저장 기능이 있습니다. 자동 테스트 64개와 TypeScript 검사, APK 서명 및 ARM64 검증을 통과했습니다.

실제 휴대폰 실행과 V9 Excel 원본 대조는 미검증입니다. 엔지니어링 선별용이며 안전·설계·벤더 승인에 단독 사용하지 마세요.
